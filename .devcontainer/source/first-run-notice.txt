👋 Bienvenue dans votre codespace de R5.Real.10, Nouveaux paradigmes de base de données.

📖 L'énoncé est le README.md du dépôt (clic droit sur le fichier, puis « Ouvrir l'aperçu »).
🍃 MongoDB démarre tout seul avec le codespace : vérifiez-le avec r510-mongo status.
   Neo4j se démarre avec r510-neo4j start, seulement quand l'énoncé le demande.
✅ r510-verifier lance le correcteur automatique ; r510-recharger remet les données du TP.
💾 r510-sauver sauvegarde votre travail sur GitHub ; r510-rendre le rend pour qu'il soit noté.
⏹️ En fin de séance, arrêtez le codespace (menu Codespaces, puis Stop codespace) :
   un codespace allumé consomme votre quota.
